### Шаг 11. Решить вопрос с Яндекс Метрикой

Статус: отложено до юридической проверки.

Решение нужно принимать вместе с юридическим направлением, потому что Метрика может требовать корректного описания аналитики/cookies в публичных документах.

Предварительный безопасный вариант:

- поставить Метрику без Вебвизора на первом этапе;
- настроить базовые цели: регистрация, вход, переход на приложение, просмотр тарифов, просмотр контактов;
- обновить юридические тексты, если требуется;
- после этого привязать счётчик к Яндекс.Вебмастеру.

Критерий готовности:

- принято решение `ставим сейчас` или `откладываем`;
- если ставим, есть список правок для юридических документов.
