# План исправления брендовой индексации Письмолёта

Дата: 2026-07-08  
Раздел: SEO и маркетинг  
Статус: в работе

## 1. Цель

Добиться нормальной брендовой выдачи по запросам:

- `Письмолёт`;
- `Письмолет`;
- `pismolet`;
- `pismolet.ru`.

Минимальный желаемый результат:

- сайт `https://pismolet.ru/` находится по брендовым запросам;
- в Яндексе сайт показывается выше GitHub-репозитория по запросу `pismolet`;
- сниппет главной страницы показывает нормальное описание, а не текст `Владелец сайта предпочёл скрыть описание страницы`;
- Яндекс.Вебмастер использует `https://pismolet.ru/` как основной адрес сайта;
- sitemap используется индексирующим роботом.

## 2. Текущие наблюдения

По ручной проверке от 2026-07-08:

- `robots.txt` доступен: `https://pismolet.ru/robots.txt`;
- `sitemap.xml` доступен: `https://pismolet.ru/sitemap.xml`;
- главная страница доступна в браузере;
- Яндекс.Вебмастер показывает, что сайт добавлен как `http://pismolet.ru:80`;
- в диагностике есть рекомендация `Главный адрес сайта не использует HTTPS-протокол`;
- в диагностике есть рекомендация `Нет используемых роботом файлов Sitemap`;
- есть рекомендация `Файл favicon не найден`;
- есть рекомендация `Укажите регион вашего сайта`;
- есть рекомендация `Счётчик Яндекс Метрики не привязан к сайту`;
- критических ошибок безопасности, robots.txt, 5xx, DNS и доступности главной не видно.

## 3. Порядок действий

### Шаг 1. Добавить HTTPS-версию сайта в Яндекс.Вебмастер

Действие в интерфейсе Яндекс.Вебмастера:

1. Добавить сайт именно как `https://pismolet.ru/`.
2. Подтвердить права.
3. Проверить, что в списке сайтов появился HTTPS-вариант, а не только `http://pismolet.ru:80`.

Критерий готовности:

- в Яндекс.Вебмастере есть отдельный сайт `https://pismolet.ru/`;
- сайт подтверждён.

### Шаг 2. Назначить HTTPS главным адресом

Действие:

1. В настройках индексирования / зеркал выбрать `https://pismolet.ru/` как главный адрес.
2. Проверить, что `http://pismolet.ru/` перенаправляет на `https://pismolet.ru/` через 301 redirect.

Критерий готовности:

- Яндекс.Вебмастер не ругается на главный адрес без HTTPS;
- HTTP-версия не конкурирует с HTTPS-версией.

### Шаг 3. Добавить sitemap вручную

Действие в Яндекс.Вебмастере:

1. Открыть раздел `Индексирование → Файлы Sitemap`.
2. Добавить `https://pismolet.ru/sitemap.xml`.
3. Проверить, что файл принят без ошибок.

Критерий готовности:

- sitemap отображается в Яндекс.Вебмастере как добавленный и обработанный;
- рекомендация `Нет используемых роботом файлов Sitemap` исчезает после обновления данных.

### Шаг 4. Отправить основные страницы на переобход

Действие:

Отправить на переобход:

- `https://pismolet.ru/`;
- `https://pismolet.ru/sitemap.xml`;
- `https://pismolet.ru/articles/`;
- `https://pismolet.ru/rassylka-klientam/`;
- `https://pismolet.ru/rassylka-pisem/`.

Критерий готовности:

- страницы поставлены в очередь переобхода;
- через несколько дней в выдаче появляется нормальный сниппет.

### Шаг 5. Добавить favicon в корень сайта

Действие в репозитории:

- добавить `public_html/favicon.svg`;
- по возможности добавить `public_html/favicon.ico`;
- оставить существующий favicon в `/assets/brand/favicon.svg`.

Критерий готовности:

- `https://pismolet.ru/favicon.svg` доступен;
- `https://pismolet.ru/favicon.ico` доступен, если добавлен;
- рекомендация Яндекса по favicon исчезает после переобхода.

### Шаг 6. Указать регион сайта

Действие в Яндекс.Вебмастере:

- указать регион сайта: `Россия`, если интерфейс позволяет выбрать страну;
- если требуется город, выбрать фактический город владельца/проекта.

Критерий готовности:

- рекомендация `Укажите регион вашего сайта` закрыта.

### Шаг 7. Проверить свежесть продакшена

Действие:

Проверить, что на `https://pismolet.ru/` выкачена свежая версия главной страницы с текстом:

> Письмолёт отправит рассылку со своего адреса — вам не нужно рассылать её с рабочей почты.

Критерий готовности:

- продакшен содержит последние SEO-правки;
- скрин/HTML главной не показывает старый вариант первого экрана.

### Шаг 8. Усилить брендовые сигналы на сайте

Действие в репозитории:

- проверить главную, контакты и футер на наличие связки `Письмолёт / Письмолет / pismolet / pismolet.ru`;
- не переспамливать ключами, но явно связать кириллическое название, написание без `ё` и латиницу.

Критерий готовности:

- на главной и странице контактов явно есть брендовая связка;
- сниппет постепенно начинает подтягивать нормальное описание.

### Шаг 9. Обновить GitHub About

Действие в GitHub:

- добавить сайт `https://pismolet.ru/` в поле Website;
- добавить русское описание проекта;
- добавить topics: `pismolet`, `email`, `newsletter`, `письмолет`, `письмолёт`.

Критерий готовности:

- GitHub-результат в выдаче связывает репозиторий с сайтом, а не конкурирует с ним как неизвестный результат.

### Шаг 10. Метрика и Яндекс Бизнес

Действие:

- решить, ставим ли Яндекс Метрику сейчас;
- при установке проверить юридическую часть по cookies/аналитике;
- добавить организацию/онлайн-сервис в Яндекс Бизнес, если это уместно.

Критерий готовности:

- рекомендации Яндекса по Метрике и Яндекс Бизнесу обработаны или осознанно отложены.

## 4. Текущий ближайший шаг

Начать с шага 1:

> Добавить `https://pismolet.ru/` в Яндекс.Вебмастер как отдельный сайт и подтвердить права.

После этого проверить шаг 2 — главный адрес и redirect с HTTP на HTTPS.
