# Брендовая выдача Письмолёта

Дата: 2026-07-08  
Раздел: SEO и маркетинг  
Источник: ручная проверка поисковой выдачи, данные предоставлены в SEO-чате.

## 1. Наблюдение

На текущий момент брендовая выдача ещё не закрепилась.

По сообщению из SEO-чата:

- Google по запросу `Письмолёт` находит сайт;
- Google по запросу `Письмолет` без буквы `ё` сайт не находит;
- Яндекс по русскоязычному названию `Письмолёт` / `Письмолет` сайт не показывает в ожидаемом виде;
- Яндекс по запросу `pismolet` показывает:
  - нерелевантный результат `santex43.ru - проверить сайт`;
  - GitHub-репозиторий `den1s1/pismolet`;
  - результат `Ссылка на pismolet.ru` с текстом `Владелец сайта предпочёл скрыть описание страницы`.

Скриншот из проверки показывает, что Яндекс видит домен `pismolet.ru`, но сниппет и брендовая привязка ещё не сформированы.

## 2. Предварительный вывод

Проблема не в полном отсутствии сайта в индексе, а в слабом закреплении бренда и сниппета:

- бренд `Письмолёт` и вариант `Письмолет` нужно усилить на публичных страницах;
- нужно проверить, не мешают ли Яндексу meta description, robots, canonical, структура главной и отсутствие понятных брендовых упоминаний;
- нужно добавить или проверить Яндекс.Вебмастер и Google Search Console;
- нужно отправить sitemap на переобход;
- нужно добиться нормального сниппета для главной страницы.

## 3. Рекомендованные действия

### 3.1. Техническая проверка

Проверить:

1. `robots.txt` доступен и не закрывает сайт.
2. `sitemap.xml` доступен и содержит главную страницу.
3. Главная отдаёт корректный `200 OK`.
4. Нет случайного `noindex` в HTML, HTTP-заголовках или настройках хостинга.
5. Canonical главной указывает на `https://pismolet.ru/`.
6. В Яндекс.Вебмастере добавлен сайт `https://pismolet.ru/`.
7. В Google Search Console добавлен сайт `https://pismolet.ru/`.
8. Sitemap отправлен в Яндекс.Вебмастер и Google Search Console.
9. Главная отправлена на переобход.

### 3.2. Контентная проверка главной

На главной странице должны явно встречаться:

- `Письмолёт`;
- `Письмолет`;
- `pismolet`;
- `pismolet.ru`;
- понятное описание сервиса в первом экране и meta description.

Важно не превращать страницу в набор ключевых слов. Вариант без `ё` уже можно объяснять как альтернативное написание названия.

### 3.3. Внешние сигналы

Полезно постепенно добавить:

- страницу/профиль проекта там, где это уместно;
- ссылку на сайт из GitHub `About`, чтобы GitHub-результат передавал понятную связь с доменом;
- брендовые ссылки из публичных документов, если они уместны;
- страницу контактов с названием, доменом и email.

## 4. Приоритет

Приоритет высокий, потому что брендовый поиск должен работать раньше, чем начнут приходить пользователи из статей и органики.

Ближайшее действие после фиксации наблюдения:

1. Проверить и при необходимости усилить главную под `Письмолёт / Письмолет / pismolet`.
2. Проверить публичные meta-теги и сниппет главной.
3. Проверить Яндекс.Вебмастер, Google Search Console, sitemap и переобход.
