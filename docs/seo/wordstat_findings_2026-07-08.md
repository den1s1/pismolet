Дата: 2026-07-08

Источник: ручная проверка Wordstat, данные предоставлены в SEO-чате.

## 1. Проверка кластера `без домена / без своей почты`

Результат: прямого спроса почти нет.

- `рассылка без своего домена` — нет подходящих запросов;
- `email рассылка без домена` — нет подходящих запросов;
- `рассылка без корпоративной почты` — нет подходящих запросов;
- `рассылка без своей почты` — нет подходящих запросов;
- `отправить рассылку не со своей почты` — нет подходящих запросов;
- `как сделать рассылку без домена` — нет подходящих запросов.

Вывод:

- формулировки про домен, свою почту и корпоративную почту не подходят как главный SEO-вход;
- уникальность `Письмолёт отправляет со своего адреса` остаётся важным продуктовым аргументом, но её нужно использовать внутри страниц, а не строить вокруг неё основную посадочную;
- для нетехнической аудитории слово `домен` не должно быть первым объяснением.

## 3. Итоговые выводы

1. Кластер `без домена / без своей почты` не подтверждён как самостоятельный SEO-вход.
2. Уникальность `Письмолёт отправляет со своего адреса` нужно оставить как объяснение преимущества внутри страниц.
3. Самый сильный бытовой вход из текущей проверки — `как сделать рассылку в почте`, особенно `Яндекс Почта`.
4. Второй важный вход — `как сделать рассылку клиентам`.
5. Третий слой — `нескольким адресатам`, `скрытая копия`, `скрыть получателей`, `Excel`.
6. Не стоит начинать с лобовой страницы `/servis-rassylok/`.

## 4. Рекомендуемый следующий план

### Приоритет 1

Создать статью:

> Как сделать рассылку в Яндекс Почте и когда лучше использовать отдельный сервис

Цель статьи:

- поймать пользователя, который пытается решить задачу в обычной почте;
- честно объяснить, когда Яндекс Почты достаточно;
- показать ограничения обычной почты для 50–1000 адресатов;
- перевести на страницы `/rassylka-pisem/`, `/rassylka-klientam/`, `/bcc-alternative/`.

### Приоритет 2

Создать или усилить статью:

> Как сделать рассылку клиентам

Цель:

- поддержать `/rassylka-klientam/`;
- закрыть запрос 212;
- объяснить простой процесс: письмо → список адресов → проверка → оплата → отправка.

### Приоритет 3

Усилить `/bcc-alternative/` и `/excel-email-list/` не как главные SEO-входы, а как supporting pages.

На главной и `/no-domain-setup/` оставить формулировку:

Но не строить отдельный SEO-кластер вокруг `без домена`, пока спрос не подтверждён.
